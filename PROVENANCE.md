## Browser for tests

Chromium build 1194 (Playwright's build), pre-installed in the cloud container at `/opt/pw-browsers`. It is tooling, not an asset (spec v1 §15). `playwright.config.ts` points at it and never downloads a browser.

## Fonts

None bundled. The UI uses the system serif fonts (Georgia, Times New Roman, or the platform's fallback). No web fonts are fetched.

## Generated content

All geometry, colours, sketches and sounds are made at runtime from the JSON data in `src/world/` and the code in `src/gen/`, `src/render/` and `src/audio/`. Screenshots in `REVIEW/` are taken from this build.
